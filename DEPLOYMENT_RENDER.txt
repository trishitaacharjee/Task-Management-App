TOKI - SINGLE RENDER DEPLOYMENT

Render service settings (repository root):
- Root Directory: leave blank
- Build Command:
  npm install --prefix backend && npm install --prefix frontend && npm run build --prefix frontend
- Start Command:
  npm start --prefix backend

No Vercel environment variable is needed for this single-service deployment.

The production frontend uses /api automatically, so the browser talks to the same Render URL:
  https://YOUR-RENDER-SERVICE.onrender.com/api/...

Local development still uses:
  http://localhost:4000/api
